# Лабораторная работа №2: Подготовка скриптов для создания таблиц и добавления данных

## Описание
Утилита для автоматического создания и заполнения базы данных `movies_rating.db` на основе исходных текстовых файлов.

## Требования к окружению
Для корректной работы скрипта `db_init.bat` необходимо наличие следующих инструментов в системном PATH:
1. **Python 3.x** (команда `python3` должна выполняться из терминала).
2. **SQLite3** (консольная утилита `sqlite3`).
3. **Git Bash** (для Windows) или терминал Linux/macOS для выполнения shell-скрипта с шебангом.

## Структура файлов
- `make_db_init.py` — Python-скрипт, парсящий данные и генерирующий `db_init.sql`.
- `db_init.bat` — Shell-скрипт запуска (генерация SQL + импорт в БД).
- `movies.csv` — каталог фильмов.
- `ratings.csv` — таблица оценок пользователей.
- `tags.csv` — пользовательские теги к фильмам.
- `users.txt` — профили пользователей.
- `genres.txt` — справочник жанров.
- `occupation.txt` — справочник профессий.
- `db_init.sql` — генерируемый SQL-файл.
- `movies_rating.db` — итоговая база данных SQLite.

## Запуск
1. Откройте терминал в папке `Task02`.
2. Выполните команду:
   ```bash
   ./db_init.bat
